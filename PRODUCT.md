# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Vietnamese student revising IT English, software project management and introductory image processing on desktop and mobile.

## Product Purpose
Help the user remember course material through recall, flashcards, practice questions and review of mistakes.

## Capabilities and Constraints
- Static HTML, CSS and JavaScript, without a build step or production dependencies.
- Preserve all question banks, grading logic, subject switching and browser-local progress.
- Project management: 38 questions, reading, flashcards, recall and essay practice.
- Image processing: 400 questions in eight groups of 50; inferred answers explicitly labeled as reference answers.
- User wants minimal redundant text, clear study content and a full visual redesign with noticeable interaction effects.
- Honor reduced motion, keyboard access, mobile layouts and readable contrast.
- Optional anime companion reacts to study results and milestones, with independently muted prerecorded synthetic Japanese encouragement. It never changes grading or progress.

## Brand Commitments
The user selected a bright paper-colored interface with a prominent orange accent.
